.Kenya Census Population Analysis (2019)
A data science project analyzing county-level
population distribution and density using the
2019 Kenya Population and Housing Census (KNBS),
with a simple population projection to 2029.
1. What's in this repo
- kenya_census_analysis.ipynb - full analysis code
- kenya_census_2019.csv - cleaned dataset (47 counties)
- Kenya_Census_Project_Report.pdf - final written report
2. Tools used
Python, pandas, matplotlib, Google Colab
3. Key findings
- Nairobi City, Kiambu, and Nakuru are the most
populous counties
- Nairobi, Mombasa, and Kisumu have the highest
population density
- Projected 2029 population uses the national
2.2% inter-censal growth rate
